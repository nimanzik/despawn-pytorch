# Monthly sunspot data

`monthly-sunspots.csv` is an unchanged copy of the data file from the original
[DeSpaWN repository](https://github.com/MichauGabriel/DeSpaWN).

The original repository includes the file with the TensorFlow example for the
paper:

> Michau, G., Frusque, G., and Fink, O. (2022). Fully learnable deep wavelet
> transform for unsupervised monitoring of high-frequency time series.
> Proceedings of the National Academy of Sciences, 119(8).

The original repository is distributed under the MIT license. Its license is
included in this directory.
